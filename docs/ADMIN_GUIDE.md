# Admin Guide

Phase 1 provides the foundation for administration: the
`AdminUser` model, the audit log model, and the system settings
model. The full dashboard, authentication, roles, and controls
arrive in Phase 8.

Planned dashboard pages (Phase 8): Login, Overview, Telegram
Management, Alpha Intelligence, Airdrop Management, Prime Sale
Management, Competition Management, Competition Volume Analytics,
Market Intelligence, Futures Intelligence, News Management,
Listings and Delistings, Notification Settings, Message Templates,
API Integrations, Scheduler and Background Jobs, Admin Users and
Permissions, Audit Logs, System Health, and Backup and Restore
Status.

Until Phase 8, administration is by configuration in `.env` and
by direct database settings only. No dashboard control is
presented as functional before its backend implementation exists.
